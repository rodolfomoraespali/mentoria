# 🩺 MedPaliativa — Mentoria em Cuidados Paliativos
Landing page profissional desenvolvida para divulgação da mentoria **MedPaliativa: Decisão, Cuidado e Presença**.
O projeto foi construído utilizando **HTML5, CSS3 e JavaScript puro**, com foco em:

- ✔ Layout moderno
- ✔ Responsividade (mobile-first)
- ✔ Estrutura organizada e limpa
- ✔ Boa hierarquia visual
- ✔ Experiência de conversão

## 🚀 Tecnologias Utilizadas
- HTML5
- CSS3 (Flexbox + Grid)
- JavaScript (DOM manipulation)
- GitHub Pages

## 📱 Responsividade
A página foi projetada para funcionar perfeitamente em:
- Desktop
- Tablet
- Smartphones

## 🎨 Design
A identidade visual foi construída com uma paleta personalizada inspirada em tons:
- Creme
- Lavanda
- Roxo profundo
- Verde oliva
- Verde sálvia

## 📌 Funcionalidades
- Navegação suave
- Botões com abertura em nova aba
- Integração com WhatsApp
- Layout estruturado para conversão
- Estrutura modular e fácil de editar
